# Project Identity

This project is a premium AI scheduling app.

The app helps users turn messy tasks into a clean visual daily timeline.

Core product idea:

AI plans the day. The user adjusts it like moving blocks.

The app should feel more like a premium creative tool than an office productivity tool.

## Target Users

- students
- design majors
- young creators
- freelancers
- people who dislike traditional calendars
- people who procrastinate but want structure
- people who care about visual quality

## Product Personality

The app should feel:

- premium
- calm
- polished
- soft
- visual
- intelligent
- focused
- slightly futuristic
- friendly but not childish
- efficient but not corporate

Avoid making it feel like:

- a dashboard
- a spreadsheet
- a generic todo app
- a boring calendar
- an enterprise SaaS tool
- a default mobile template

## Visual References

The project has three design references.

Reference 1:
Overall UI quality should reference the rounded soft app UI:
- large rounded corners
- soft shadows
- spacious card layout
- polished demo-app feeling
- strong spacing
- refined proportions

Do not copy the music app content.
Only learn from its visual language, radius, shadow, spacing, and premium feeling.

Reference 2:
Bottom tab bar should reference the capsule tab bar:
- floating capsule container
- embedded selected tab state
- soft shadow
- clean icons
- premium interaction
- no default system tab bar

Reference 3:
Color palette should reference the blue palette:
- primary blue: #47709B
- soft blue: #AFC8DA
- white text: #FEFFFF
- deep dark background
- restrained, high-end, unified color system

## Main Visual Direction

Use a premium dark blue-gray UI style.

Main characteristics:

- large rounded corners
- soft shadows
- spacious layout
- card-based composition
- refined dark surfaces
- blue-gray palette
- floating capsule tab bar
- clear visual hierarchy
- high-quality mobile app feeling

The app should look like it belongs in App Store screenshots.

## Main Screen Requirements

The Today screen is the most important screen.

It should include:

- today's date
- emotional headline
- short supportive description
- natural language input card
- auto schedule action
- visual timeline
- draggable task blocks
- floating capsule tab bar

The natural language input area is the core product entry.
It should not look like a plain input field.

## Timeline Requirements

The timeline should feel visual and tactile.

Each time block should include:

- task title
- time range
- duration
- task type icon
- completion state

Task blocks should feel draggable.

A selected or dragged block should:

- lift slightly
- show stronger shadow
- scale subtly
- feel active

## Tab Bar Requirements

Use a floating capsule tab bar.

The tab bar should have:

- outer capsule container
- soft shadow
- translucent or elevated surface
- embedded selected tab capsule
- clear icon state
- subtle active transition

Do not use:

- default browser tabs
- default native tab bar
- square nav buttons
- full-width hard bottom bar

## Interaction Rules

Use subtle motion.

Recommended interactions:

- cards fade and slide in
- time blocks lift on hover or drag
- selected tab glides smoothly
- buttons have pressed state
- input focus has soft glow
- completed tasks soften visually

Avoid excessive cartoon animation.

Motion should feel calm and useful.

## Code Quality Rules

Keep components clean and reusable.

Prefer component structure such as:

- AppShell
- TodayHeader
- NaturalLanguageInputCard
- AutoSchedulePanel
- TimelineView
- TimeBlockCard
- QuickTaskChips
- FloatingTabBar
- FocusPanel
- ReviewCard

Avoid one huge file.

Avoid duplicated design values.

## Forbidden Styles

Never create:

- admin dashboard style
- generic Todo app style
- generic calendar template
- default blue buttons
- default system tab bar
- dense forms
- random gradients
- random colors
- inconsistent radius
- inconsistent shadows
- cramped spacing
- table-heavy layout

## Final UI Checklist

Before finishing, check:

1. Does the screen look like a premium consumer app?
2. Does it avoid admin dashboard feeling?
3. Are radius values consistent?
4. Are shadows soft and intentional?
5. Is the color system controlled?
6. Is there enough breathing room?
7. Is the tab bar a floating capsule?
8. Do time blocks feel tactile and draggable?
9. Is the main action obvious?
10. Would this look acceptable in an App Store screenshot?

If not, continue refining.
